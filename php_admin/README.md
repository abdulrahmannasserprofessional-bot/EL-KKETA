# 🎓 لوحة تحكم وإدارة منصة الخطة التعليمية (PHP + Firebase Backend)

لوحة تحكم إدارية متكاملة وسريعة مبنية بلغة **PHP** وتتصل مباشرة بقاعدة بيانات **Firebase Realtime Database** و **Firebase Cloud Messaging (FCM)** لإدارة منصة الخطة وتطبيق الموبايل.

---

## 🚀 المميزات الرئيسية:
1. **لوحة الإحصائيات (Dashboard):**
   - إحصائيات حية لعدد الطلاب، المحاضرات، الأكواد المتاحة، والامتحانات مباشرة من Firebase.
2. **إدارة الطلاب (Students Management):**
   - استعراض الطلاب، البحث المتقدم، حظر/فك حظر الحسابات، فك قفل الجهاز (Device Reset)، تعديل بيانات الطالب وحذف الحسابات.
3. **الكورسات والمحاضرات (Courses & Lectures):**
   - إضافة وتعديل المحاضرات، روابط الفيديو (YouTube/Bunny/HLS)، مذكرات PDF، التسعير والمحاضرات المجانية.
4. **أكواد الشحن والتفعيل (Recharge Codes):**
   - توليد حزم أكواد مخصصة دفعة واحدة (Bulk Generation)، تحديد القيمة والنوع، تصدير الأكواد إلى ملف Excel/CSV، وتنظيف الأكواد المستهلكة.
5. **الامتحانات والواجبات (Exams & Quizzes):**
   - منشئ امتحانات تفاعلي (MCQ)، تحديد الوقت بالدقائق والدرجة الكلية، والتصحيح التلقائي.
6. **الإشعارات الفورية (Push Notifications):**
   - إرسال إشعارات مباشرة لجميع الطلاب أو لصف دراسي محدد مع معاينة حية لشكل الإشعار على الموبايل وسجل الإشعارات المرسلة.
7. **إعدادات المنصة والبوابة (Settings & Gate):**
   - تفعيل/تعطيل وضع الصيانة للمنصة، رسالة التنبيه، رقم واتساب الدعم، فحص الاتصال مع السيرفر، وإدارة حسابات المشرفين.

│   ├── exams.php                 # معالج الامتحانات

├── students.php                  # صفحة إدارة الطلاب
├── courses.php                   # صفحة إدارة المحاضرات
├── codes.php                     # صفحة أكواد الشحن

> *يمكنك تغيير هذه البيانات من ملف `config/config.php` أو من شاشة الإعدادات.*

---

## 💻 طريقة التشغيل والرفع:

### 1. التشغيل المحلي (Localhost):
- قم بنسخ مجلد `php_admin` داخل مجلد السيرفر المحلي (مثل `htdocs` في XAMPP أو `www` في Laragon).
- أو عبر التيرمينال باستخدام سيرفر PHP الداخلي:
  ```bash
  cd php_admin
  php -S localhost:8000
  ```
- افتح المتصفح على الرابط: `http://localhost:8000`

### 2. الرفع على استضافة (cPanel / Hostinger / VPS):
- قم بضغط مجلد `php_admin` ورفعه داخل `public_html` أو في مجلد فرعي مثل `public_html/admin`.
- تأكد من تفعيل إضافة `cURL` و `OpenSSL` في إعدادات PHP على السيرفر (مفعلة تلقائياً في أغلب الاستضافات).

---

## ⚙️ ربط وتأمين Firebase:
1. في ملف `config/config.php`:
   - الرابط مضبوط مسبقاً على مشروعك: `https://elkhotta-default-rtdb.europe-west1.firebasedatabase.app`
   - إذا أردت استخدام **Database Secret**، احصل عليه من:
     `Firebase Console` > `Project Settings` > `Service accounts` > `Database secrets`.
   - لدعم إشعارات FCM الحديثة (HTTP v1)، يمكنك وضع ملف `service-account.json` داخل مجلد `config/`.
