📜 ميثاق الأمان وقوانين منصة الخطة

1️⃣ الخطوة الأولى: تسجيل البيانات

يتم تسجيل اسمك الثلاثي لظهور شهادات التقدير وبطاقات الأداء الأكاديمي باسمك الدقيق، ورقم الواتساب لربط التنبيهات.

2️⃣ الخطوة الثانية: كود الطالب الفريد

فور إتمام التسجيل، يتم إصدار "كود الطالب الأكاديمي" (مثال: S1234). يرجى الاحتفاظ بهذا الكود لأنه مفتاح دخولك الدائم للمنصة.

🛡️ منظومة حماية الحسابات

منظومة الخطة مؤمنة بنظام ذكي لمنع مشاركة الحسابات وحماية خصوصية الطلاب:

  • يُسمح بالدخول من جهازين فقط (مثلاً: الهاتف الشخصي وجهاز الكمبيوتر).
  • ممنوع تداول الكود مع أي طرف آخر لضمان عدم حظر الحساب تلقائياً.
